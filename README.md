# ScreenSwitch · 内置屏幕开关

**简体中文** | [English](README.en.md)

让 MacBook 保持开盖，只用外接显示器工作，同时继续使用内置键盘和触摸板。

通过一个简单开关尝试真正停用内屏桌面输出，而不是把亮度调为零或盖上黑色窗口。提供控制窗口、Dock 和菜单栏入口，不怕菜单栏图标被刘海遮住。

*v0.2.2 界面实拍：开关随内屏状态变化，支持只读刷新和中英文切换。*

> **实验性工具：** 使用 macOS 未公开支持的接口，兼容性和恢复效果无法保证。已通过构建、界面和模拟检查，但这不代表所有机型均兼容。首次使用前请了解下方恢复方法。

## 下载与安装

前往 [Releases](https://github.com/haroldvandy2013/ScreenSwitch/releases/latest)，下载 **ScreenSwitch-v0.2.2-macos-arm64.zip**。解压后将 **ScreenSwitch.app** 放入“应用程序”文件夹即可。关屏和恢复功能已合并，无需另装恢复应用。

更新前请先确认内屏已经开启，再退出旧版并替换应用。旧版卡住时，不要在内屏关闭状态下强制退出。

从旧版 v0.1.0 升级时，先正常退出旧程序，再替换主应用。确认新版正常退出能够恢复内屏后，可以删除旧的“恢复内置屏幕.app”。

下载包仅适用于 **Apple Silicon Mac，macOS 13 或以上**。开发环境为 M3 Max / macOS 15.8.1，但不代表已验证此机型关屏可靠。

应用未经 Apple 公证。如果系统阻止打开，可尝试右键选择“打开”，或在系统设置中选择“仍要打开”；**不要关闭系统安全保护**。

## 怎么用

1. 保持笔记本打开，接上并唤醒外接显示器，确认外屏能正常显示桌面。
2. 打开 ScreenSwitch，点击 **关闭内置屏幕**，阅读提示后确认。没有可用外屏时，此按钮不可用。
3. 需要内屏时，点击 **恢复内置屏幕**。

窗口底部或菜单中的 **语言 / Language** 可切换“简体中文”和“English”，立即生效并记住选择；首次打开默认中文。

窗口右上角显示版本号。点击 **刷新** 只重新检测显示状态，不执行关屏或恢复；内屏开启时只显示“关闭内置屏幕”，关闭时只显示“恢复内置屏幕”。已经开启的内屏不会重复执行恢复。

源码与本地修复版本为 **v0.2.4**（下载版仍为 v0.2.2）：自动恢复依据已有恢复记录或本次运行的关屏意图触发，不把正常熄屏、休眠或唤醒时的暂时不活动误判为软件关屏。内屏在至少两秒的连续观测中保持活动、且显示配置未变化后，才清除恢复记录，避免一次短暂活动导致拔线保护丢失。

**可选：熄屏时自动恢复内置屏幕。** 默认不勾选，只有开启后，显示器熄屏时才会自动尝试恢复被本软件关闭的内屏输出，并记住你的选择。这里指显示器熄屏，不是仅锁屏或显示屏保；不重启电脑，也不发送唤醒命令，实际亮屏行为取决于系统。唤醒后不会再次自动关闭内屏。

最后一个可用外屏断开时，程序会尝试自动恢复内屏；休眠和正常退出时也会尝试恢复。外屏重新连接或系统唤醒后，**不会自动关屏**。

上述系统休眠、拔线和退出时的安全恢复始终保留，不受熄屏选项影响。

拔掉最后一个外屏时会立即请求恢复，并持续检查内屏是否重新活动。若普通恢复失败，且已没有外屏，会额外尝试恢复 macOS 已保存的显示配置，**可能重置显示排列**；仍不能保证所有机型或驱动故障下都能恢复。

关闭窗口不会退出程序。点击 Dock 图标或重新打开应用时，若有待恢复记录，会先尝试恢复再显示窗口。没有记录但确实需要恢复时，可点击 **刷新** 后手动选择 **恢复内置屏幕**。退出请使用 **恢复屏幕并退出**，不要强制退出。

## 如果黑屏了

首次关屏前，先确认你能找到 ScreenSwitch；如果打算用 Spotlight 搜索，请先确认它已被索引。

1. 接回并唤醒外接显示器，尝试点击 **恢复内置屏幕**。
2. 重新打开 **ScreenSwitch.app**，程序会优先尝试恢复；也可通过 Spotlight 搜索“ScreenSwitch”打开。如果程序已卡死，重新打开可能无效，请继续下一步。
3. 尝试合盖再开盖。仍无法恢复时，重新启动 Mac，注意未保存的数据。

**崩溃、强制退出或系统故障时，自动恢复不能保证。** 首次使用建议直接连接实体外屏，不要把虚拟屏或远程桌面当作唯一保障，也不要同时运行其他关屏软件。若关屏或恢复失败，请停止继续尝试。

### 问题日志

v0.2.4 起会在 macOS 本地统一日志中记录显示状态变化、拔插回调、休眠/唤醒、恢复触发原因、恢复记录写入/清除，以及显示接口各阶段的返回码；不记录屏幕内容，不上传日志。下次遇到问题，请记下时间、是否已经接回外屏，并保留应用运行。菜单中的 **复制只读诊断** 可复制当前状态；最近一天的事件可在终端导出：

```bash
/usr/bin/log show --last 1d --style compact --predicate 'subsystem == "local.ScreenSwitch"' > ~/Desktop/ScreenSwitch.log
```

日志保留时间由 macOS 管理；当前状态正常不代表问题发生时的状态正常。

<details>
<summary>从源码构建</summary>

需要 Swift 6.0 或以上及 Xcode Command Line Tools。

```bash
git clone https://github.com/haroldvandy2013/ScreenSwitch.git
cd ScreenSwitch
./build.sh
```

只会生成 `dist/ScreenSwitch.app`，默认构建当前 Mac 的处理器架构。也可在终端运行 `./dist/ScreenSwitch.app/Contents/MacOS/ScreenSwitch --restore`，仅尝试恢复内屏，不关屏。

</details>
